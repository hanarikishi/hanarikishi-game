# ランキング（Firebase）の作りかた

このフォルダは名前が `_` で始まるので、GitHub Pages では公開されません。

ゲームの記録は、いつも **この端末** に保存されます（今日・今週・今月・通算のベスト）。
下の手順を済ませると、**みんなの順位**（日・週・月・通算のトップ20）も出るようになります。

- 対象のゲーム: 出世・フラッピー・クロッシー・スタック・ブロック崩し・サバイバーズ・将棋・シュート（エンドレス）・はっけよい。
  「どすこい！はなりきし」には付けていません。
- 日・週・月は **日本時間** で切りかわります。
- 保存するのは「名前（12文字まで）・点数」だけです。名前は、ランキングの画面の「名前:」ボタンで変えられます。
- 名前には、下ネタ・乱暴な言葉・Fワードなどは使えません。「どすこい！はなりきし」の四股名と同じ禁止ワード（`ngwords.js`）で、ゲームの側で判定します。言葉を足すときは、`life/src/data/ngwords.js` と `ngwords.js` の両方に足します。

## 手順（ブラウザで、あなたのGoogleアカウントで行います）

1. https://console.firebase.google.com/ を開き、**プロジェクトを追加** する（名前は自由。Googleアナリティクスは「無効」でよい）。
2. 左の「構築」→ **Authentication** →「始める」→ ログイン方法で **匿名** を有効にする。
3. 左の「構築」→ **Firestore Database** →「データベースを作成」。
   ロケーションは **asia-northeast1（東京）**。モードは「本番環境モード」でよい。
4. Firestore の **ルール** のタブを開き、`_docs/firestore.rules` の中身を全部貼って「公開」。
5. 歯車 →「プロジェクトの設定」→ 下の「マイアプリ」で **ウェブ（`</>`）** を追加（アプリ名は自由。Hosting は不要）。
6. 表示された `firebaseConfig` の `apiKey`・`authDomain`・`projectId`・`appId` を、リポジトリ直下の `firebase-config.js` に貼る。
7. `git push` する。1〜2分で、ランキングが動きます。

`apiKey` などは、ウェブアプリの設定として **公開される前提の値** です。秘密ではありません。守っているのは手順4の **ルール** です。

## つくりのメモ

- データの場所: `ranks/{ゲームid}/{期間}/{uid}`。期間は `d_2026-10-24`（日）・`w_2026-W43`（週）・`m_2026-10`（月）・`all`（通算）。
- 1人（匿名ログインの uid）につき、期間ごとに1件。いまより良い記録のときだけ書きかえます。
- 「低いほど良い」ゲーム（はっけよい）は、`dir: 'asc'`。ほかは `desc`。
- 順位を出す問い合わせは、1つのフィールドの並べかえだけなので、Firestore の複合インデックスは要りません。
- 名前のチェックは、ゲームの画面での判定だけです。Firebase に直接書きこまれた名前までは防げません（見つけたら、Firebase の画面から消します）。
- **スコアの偽造は完全には防げません**（ルールは点数の範囲と、いまより良いかどうかしか見ません）。気になる記録は、Firebase の画面から消せます。

## 無料枠の目安（公式ページで要確認）

Firestore の無料の枠は、1日に読み取り5万回、書き込み2万回、保存1GiB くらいです。ランキングを開くたび、1つの期間につき最大20件を読みます。
