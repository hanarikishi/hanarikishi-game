# これから作るゲームと、必要な素材

このフォルダは名前が `_` で始まるので、GitHub Pages では公開されません。
素材は「誰が用意するか」で分けています。**用意してほしい** はこちら（はなりきしの作者）にしか作れないもの、**仮のもので可** はいまは Claude がコードで代わりを作っているものです。

いまある共通の絵（`parts/`）: 正面を向いた丸い体（体の色・まわし・線）、顔3種類（ふつう・ぶつかった・勝ち）、ホームのアイコン。

---

## 作る予定

### ふにゃりきし（ぐらぐら押し相撲・ふたり対戦）
腕や脚がぶらぶらする力士を、ボタン1つで動かして押し合う。思いどおりに動かないのが面白さの中心。

- **用意してほしい**
  - 体のパーツに分かれた絵: 頭・胴・左右の腕・左右の脚（透明PNG、正面と横向き）
  - 各パーツの関節の位置（肩・股など。絵の上に点を打ったものでよい）
- **仮のもので可**: 土俵・背景・効果音
- パーツの絵がないときの代わり: 丸い体が起き上がりこぼしのように揺れて押し合う簡易版なら、いまの素材で作れる

### はなりきしタワー（どうぶつタワーバトル風）
いろいろな格好のはなりきしを落として、崩れないように積み上げる。

- **用意してほしい（あると本家に近づく）**
  - ポーズ違いの絵を5〜10種類: 寝ころび・四股・逆立ち・バンザイ・体育座り・四つんばい など（透明PNG）
- **仮のもので可**: 体を伸び縮みさせた形、米俵や鍋を持たせた形で代わりにできる（いまの素材だけで作れる）

### はなりきし投げ（Angry Birds風）
ゴムで引っぱってはなりきしを飛ばし、米俵や櫓を崩して的を倒す。

- **用意してほしい**: なし（いまの素材で作れる）
- **あるとよい**: 飛んでいる顔・横向きの絵

## 公開中のゲームで、素材があると良くなるもの

### はなりきし 立ち合い（`tachiai/`）
いまは20面。21〜30面は `tachiai/levels.js` の `TACHIAI_LEVELS_EXTRA` に保管している（全部ヒントでクリアできることは確かめ済み）。戻すときは `TACHIAI_LEVELS` の最後に足す。

| 素材 | いまの仮のもの | あると |
|---|---|---|
| 表情: こわい・あちっ・どきどき | 3種類の顔を使い回し | 落ちる・鍋に入る・待つ場面がはっきりする |
| 立ち合いのポーズ（2人が組み合う絵） | 「はっけよい！」の文字と座布団 | クリアの瞬間が気持ちよくなる |
| 筆文字のタイトルロゴ | ふつうの太字 | 見栄え |
| BGM（和風のループ） | なし | 雰囲気 |
| 効果音・声（拍子木・太鼓・歓声・「はっけよい！」） | ブラウザで合成した音 | 手ごたえ |
| 背景（土俵・国技館など） | 和紙の模様 | 進んでいる感じ |

### はなりきしシュート（`shoot/`）

横画面（700x420）。ステージ80面（8章×10面）は `node _docs/tools/gen_shoot_stages.js` で自動生成し、1面ずつ「入る打ち方がある・簡単すぎない」ことを総当たりで確かめている。章を足すときはこの道具の `CHAPTERS` に足して作り直す。

| 素材 | いまの仮のもの | あると |
|---|---|---|
| シュートのポーズ（ボールを頭の上で構える・両手で放つ） | 正面の体を縮めたり跳ねさせたりしている | 打っている感じがはっきりする |
| 入ったときの喜びポーズ | 「勝ち」の顔 | 気持ちよさ |
| 背景（バスケのアリーナ） | コードで描いた客席・照明・広告ボード・板張りの床 | 見栄え |
| 効果音（ネットのスパッ、リングのガン、歓声）・BGM | ブラウザで合成した音 | 手ごたえ |
