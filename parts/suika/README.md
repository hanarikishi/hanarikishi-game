# はなりきし出世（パズル） の素材

置き場所: `parts/suika/`　／　使うゲーム: `suika/`

いまの状態: 番付ごとに色を変えた丸い体（11段階）

## 1. はなりきしの絵（いちばん先に欲しいもの）
| ファイル | 中身 |
|---|---|
| `rank_00.png 〜 rank_10.png` | 番付ごとの姿（前相撲〜横綱の11枚）。大きいほど、飾りや衣装が増える |
| `pose_gattai.png` | 合体の瞬間（びっくり・喜び） |

## 2. このゲームだけの絵
| ファイル | 中身 |
|---|---|
| `bg_suika.jpg（840×1400）` | 土俵や国技館の背景（いまは和紙の色） |
| `fx_gattai.png（256×256）` | 合体のエフェクト |

## 3. 音
効果音: 落とす・合体・昇進。BGM（ループ）

## 描くときの決まり（どのゲームも同じ）
- はなりきしの**ポーズ絵**は **640×640・透明PNG・右向き**（左向きは、ゲームの側で反転します）
- **足元の位置を、全部の絵でそろえる**（下から約40px）。ポーズが変わっても、体がずれて見えないように
- 線は太めに。ゲームの中では、100〜200px くらいに縮めて使います
- ファイル名は半角（`pose_run1.png` のように）。置き場所は、このフォルダ（`parts/suika/`）
- 背景は **JPG**、音は **m4a か mp3**

絵がそろったら、私がゲームに組み込みます（足りない場面は、いまの絵のままにして、あとで差しかえられるようにします）。
