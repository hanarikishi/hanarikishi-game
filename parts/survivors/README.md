# はなりきしサバイバーズ の素材

置き場所: `parts/survivors/`　／　使うゲーム: `survivors/`

いまの状態: 力士の絵（番付の色違い）、敵はコードで描いたドット絵

## 1. はなりきしの絵（いちばん先に欲しいもの）
| ファイル | 中身 |
|---|---|
| `walk_r1〜r4.png ・ walk_b1〜b4.png` | 歩く4コマ（横向きと、後ろ向き） |
| `pose_attack.png` | 突っ張り（張り手の攻撃） |
| `pose_hurt.png ・ pose_levelup.png` | ダメージを受けた・レベルアップの喜び |

## 2. このゲームだけの絵
| ファイル | 中身 |
|---|---|
| `enemy_*.png（128×128・透明）` | 敵: おばけ・こうもり・ガイコツ・天狗・ライバル力士（灰・赤）・鬼4種（赤・青・金・黒） |
| `weapon_*.png（128×128）` | 武器: 張り手・塩・軍配・米俵・四股・のぼり旗・稲妻（と、進化後の7つ） |
| `item_*.png（64×64）` | 小判・宝箱・かがり火・磁石 |
| `tile_ground.png（256×256・つなげられる絵）` | 地面。草・土の模様 |

## 3. 音
効果音: 攻撃・ヒット・レベルアップ・宝箱。BGM（ループ。30分遊ぶので、長めか、数曲）

## 描くときの決まり（どのゲームも同じ）
- はなりきしの**ポーズ絵**は **640×640・透明PNG・右向き**（左向きは、ゲームの側で反転します）
- **足元の位置を、全部の絵でそろえる**（下から約40px）。ポーズが変わっても、体がずれて見えないように
- 線は太めに。ゲームの中では、100〜200px くらいに縮めて使います
- ファイル名は半角（`pose_run1.png` のように）。置き場所は、このフォルダ（`parts/survivors/`）
- 背景は **JPG**、音は **m4a か mp3**

絵がそろったら、私がゲームに組み込みます（足りない場面は、いまの絵のままにして、あとで差しかえられるようにします）。
