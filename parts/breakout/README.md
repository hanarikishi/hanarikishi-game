# はなりきしブロック崩し の素材

置き場所: `parts/breakout/`　／　使うゲーム: `breakout/`

いまの状態: 転がる丸い体の弾、ブロックとパドルはコードで描画

## 1. はなりきしの絵（いちばん先に欲しいもの）
| ファイル | 中身 |
|---|---|
| `ball_normal.png ・ ball_hit.png ・ ball_angry.png` | 弾になるはなりきし（ふつう・ぶつかった・怒り） |
| `pose_over.png` | ゲームオーバーの絵（泣き） |

## 2. このゲームだけの絵
| ファイル | 中身 |
|---|---|
| `paddle.png（320×64）` | パドル（米俵・土俵の台など） |
| `brick_*.png（72×40）` | ブロック: 米俵・番付表・金・銀 |
| `capsule_*.png（64×32）` | パワーアップのカプセル7種 |
| `bg_round1〜8.jpg（840×1400）` | 面ごとの背景（8枚） |

## 3. 音
効果音: 反射・ブロック破壊・パワーアップ・ミス。BGM（ループ）

## 描くときの決まり（どのゲームも同じ）
- はなりきしの**ポーズ絵**は **640×640・透明PNG・右向き**（左向きは、ゲームの側で反転します）
- **足元の位置を、全部の絵でそろえる**（下から約40px）。ポーズが変わっても、体がずれて見えないように
- 線は太めに。ゲームの中では、100〜200px くらいに縮めて使います
- ファイル名は半角（`pose_run1.png` のように）。置き場所は、このフォルダ（`parts/breakout/`）
- 背景は **JPG**、音は **m4a か mp3**

絵がそろったら、私がゲームに組み込みます（足りない場面は、いまの絵のままにして、あとで差しかえられるようにします）。
