# バスケ（はなりきしシュート）の素材

置き場所: `parts/basketball/`　／　使うゲーム: `shoot/`（はなりきしシュート）

## ある絵（4枚）
どれも **640×640・透明PNG・右向き**。右手を高く上げた、シュートのポーズです。

| ファイル | 顔 | ゲームでの使いかた |
|---|---|---|
| `basket1.png` | 真剣 | **通常時**（待っているとき・ボールを放ったあとの飛んでいる間） |
| `basket2.png` | 集中（口を結ぶ） | **ひっぱっているとき**（ゴムを引いている間） |
| `basket3.png` | 笑顔 | **入った**（得点・ステージクリア） |
| `basket4.png` | 困り顔 | **外れた**（ミス・ゲームオーバー） |

- 右向きで描いてあるので、左向きが要るときは、ゲームの側で反転して使います（描き直し不要）。
- 使いかたは、教えてもらったとおりです（1=通常時、2=ひっぱっているとき、3=入った、4=外れた）。

## 描くときの決まり（追加のときも同じに）
- サイズ **640×640**、背景は**透明**のPNG、ファイル名は半角（`basket5.png` のように）
- **足元の位置を、全部の絵でそろえる**（いまの4枚は、足元が下から約40px）。ポーズが変わっても、体がずれて見えなくなります
- 線は太めのまま。ゲームの中では、100〜200px くらいに縮めて使います

## 足りないもの（あると良くなる順）
1. **ボールを両手で構える絵**（`basket5.png`）… いまは、ボールを体の前に重ねて描いています。手に持っていると、ぐっと「打つ感じ」が出ます
2. **ステージクリアの大喜び**（`basket6.png`）… 3つ星のときの、ばんざい・ジャンプなど
3. **ボール**（`ball.png`・256×256・透明）… いまはコードで描いたバスケットボールです。はなりきし風の絵にしたいとき
4. **背景**（`bg_arena.jpg`・1400×840）… 体育館・アリーナ。いまはコードで描いた客席と板張りの床です
5. **音**（`sfx/` と `bgm/`・m4a か mp3）
   - `swish`（ネットにスパッ）、`rim`（リングにガン）、`board`（ボードにコン）、`bounce`（トランポリン）、`cheer`（歓声）、`miss`（外れた）
   - `bgm`（ループ。30秒〜1分くらい）

## 組み込みについて
- `shoot/` に組み込み済みです（通常時・ひっぱっているとき・入った・外れた）。ボールを構える絵が入ったら、「ひっぱっているとき」を、そちらに差しかえます。
- 絵を `shoot/sw.js` のキャッシュ一覧に足して、オフラインでも出るようにします。
- 絵が足りない場面は、いまの丸い体のまま（仮の絵）にして、あとから差しかえられるようにします。
