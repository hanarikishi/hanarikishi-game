# はなりきし将棋 の素材

置き場所: `parts/shogi/`　／　使うゲーム: `shogi/`

いまの状態: はなりきしの顔の駒（駒の種類を点・棒で表示）

## 1. はなりきしの絵（いちばん先に欲しいもの）
| ファイル | 中身 |
|---|---|
| `koma_ou.png ・ koma_hi.png ・ koma_kaku.png ・ koma_kin.png ・ koma_gin.png ・ koma_fu.png` | 駒ごとの顔（玉・飛・角・金・銀・歩）。表情や持ち物を変える |
| `koma_*_nari.png` | 成り駒の顔（体が赤くなる） |
| `pose_win.png ・ pose_lose.png` | 勝った・負けた（結果の画面） |

## 2. このゲームだけの絵
| ファイル | 中身 |
|---|---|
| `board.png（700×900）` | 5×8の盤（木目） |
| `bg_shogi.jpg（840×1400）` | 背景（畳・和室） |

## 3. 音
効果音: 駒を打つパチッ・取る・成る・勝ち・負け。BGM（静かな和風）

## 描くときの決まり（どのゲームも同じ）
- はなりきしの**ポーズ絵**は **640×640・透明PNG・右向き**（左向きは、ゲームの側で反転します）
- **足元の位置を、全部の絵でそろえる**（下から約40px）。ポーズが変わっても、体がずれて見えないように
- 線は太めに。ゲームの中では、100〜200px くらいに縮めて使います
- ファイル名は半角（`pose_run1.png` のように）。置き場所は、このフォルダ（`parts/shogi/`）
- 背景は **JPG**、音は **m4a か mp3**

絵がそろったら、私がゲームに組み込みます（足りない場面は、いまの絵のままにして、あとで差しかえられるようにします）。
