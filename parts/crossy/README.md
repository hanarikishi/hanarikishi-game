# はなりきしクロッシー の素材

置き場所: `parts/crossy/`　／　使うゲーム: `crossy/`

いまの状態: 丸い体、車・川・電車・ワシはコードで描画（立体ブロック）

## 1. はなりきしの絵（いちばん先に欲しいもの）
| ファイル | 中身 |
|---|---|
| `hop_f.png ・ hop_b.png ・ hop_l.png ・ hop_r.png` | ジャンプの4方向（前・後・左・右） |
| `pose_squash.png ・ pose_splash.png ・ pose_eagle.png` | ひかれた・川に落ちた・ワシにつかまった |

## 2. このゲームだけの絵
| ファイル | 中身 |
|---|---|
| `car_*.png ・ truck.png ・ train.png ・ eagle.png ・ log.png` | 車・トラック・電車・ワシ・丸太 |
| `tile_grass.png ・ tile_road.png ・ tile_river.png ・ tile_rail.png（128×128）` | 地面のタイル |

## 3. 音
効果音: ジャンプ・コイン・ひかれた・水しぶき。BGM（ループ）

## 描くときの決まり（どのゲームも同じ）
- はなりきしの**ポーズ絵**は **640×640・透明PNG・右向き**（左向きは、ゲームの側で反転します）
- **足元の位置を、全部の絵でそろえる**（下から約40px）。ポーズが変わっても、体がずれて見えないように
- 線は太めに。ゲームの中では、100〜200px くらいに縮めて使います
- ファイル名は半角（`pose_run1.png` のように）。置き場所は、このフォルダ（`parts/crossy/`）
- 背景は **JPG**、音は **m4a か mp3**

絵がそろったら、私がゲームに組み込みます（足りない場面は、いまの絵のままにして、あとで差しかえられるようにします）。
