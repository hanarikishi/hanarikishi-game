# parts/ の絵の置き場所

ゲームごとに、フォルダを分けています。**各フォルダの README.md に、そのゲームで必要な絵のリストがあります。**

| フォルダ | ゲーム | 状態 |
|---|---|---|
| `basketball/` | はなりきしシュート（バスケ） | 4枚が入っていて、ゲームに組み込み済み。足りない絵は README |
| `life/` | どすこい！はなりきし | 絵のリストのみ |
| `suika/` | はなりきし出世 | 絵のリストのみ |
| `survivors/` | はなりきしサバイバーズ | 絵のリストのみ |
| `hakkeyoi/` | はっけよい！はなりきし | 絵のリストのみ |
| `flappy/` | はなりきしフラッピー | 絵のリストのみ |
| `breakout/` | はなりきしブロック崩し | 絵のリストのみ |
| `stack/` | はなりきしスタック | 絵のリストのみ |
| `shogi/` | はなりきし将棋 | 絵のリストのみ |
| `crossy/` | はなりきしクロッシー | 絵のリストのみ |

フォルダの外（`parts/` 直下）にあるのは、**全ゲーム共通の絵**です（体の色・まわし・線・顔3種・ホームの絵・アイコン）。

## 描く順番のおすすめ
1. **はなりきしの絵**（各 README の「1」）… どのゲームも、ここがいちばん効果が大きいです。特に、**横向きに歩く・走る・ジャンプする絵**は、サバイバーズ、クロッシー、シュートで使えます。
2. **ゲーム固有の絵**（各 README の「2」）
3. **背景**
4. **音**（各 README の「3」）

サイズや描くときの決まりは、各 README の最後に書いてあります（ポーズ絵は 640×640・透明PNG・右向き・足元をそろえる）。
