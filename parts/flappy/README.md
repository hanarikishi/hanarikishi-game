# はなりきしフラッピー の素材

置き場所: `parts/flappy/`　／　使うゲーム: `flappy/`

いまの状態: 丸い体の両側に、軍配（コードで描画）

## 1. はなりきしの絵（いちばん先に欲しいもの）
| ファイル | 中身 |
|---|---|
| `flap_up.png ・ flap_down.png` | 軍配をあおぐ（上・下）の2コマ |
| `pose_fall.png ・ pose_dead.png` | 落ちていく・やられた |

## 2. このゲームだけの絵
| ファイル | 中身 |
|---|---|
| `tawara_top.png ・ tawara_bottom.png` | 障害物の米俵（上から・下から） |
| `bg_flappy.jpg（840×1400）` | 背景（空・稽古場など） |

## 3. 音
効果音: あおぐ・通過・やられた。BGM（ループ）

## 描くときの決まり（どのゲームも同じ）
- はなりきしの**ポーズ絵**は **640×640・透明PNG・右向き**（左向きは、ゲームの側で反転します）
- **足元の位置を、全部の絵でそろえる**（下から約40px）。ポーズが変わっても、体がずれて見えないように
- 線は太めに。ゲームの中では、100〜200px くらいに縮めて使います
- ファイル名は半角（`pose_run1.png` のように）。置き場所は、このフォルダ（`parts/flappy/`）
- 背景は **JPG**、音は **m4a か mp3**

絵がそろったら、私がゲームに組み込みます（足りない場面は、いまの絵のままにして、あとで差しかえられるようにします）。
